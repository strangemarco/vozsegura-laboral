Funciones principales

¿Qué permite hacer el sistema?

El sistema está pensado para que la organización pueda actuar de forma ordenada, confidencial y con seguimiento documentado.

Denuncias anónimas

El trabajador puede registrar una denuncia sin exponer obligatoriamente sus datos personales.

Gestión de casos

Recursos Humanos o el Comité de Ética pueden revisar, clasificar y actualizar el estado de cada denuncia.

Reportes preventivos

Permite visualizar estadísticas básicas para identificar áreas críticas y prevenir futuros casos.

Proceso del sistema

Seguimiento claro desde el registro hasta el cierre

Cada denuncia pasa por estados definidos para evitar que los casos queden olvidados o sin respuesta.

1
Registro

El trabajador llena el formulario y adjunta evidencias.

2
Revisión

El comité analiza la información recibida y avanza el proceso.

3
Cierre

El caso finaliza con una conclusión documentada.
