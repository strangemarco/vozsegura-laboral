Canal confidencial

Registrar denuncia anónima

Completa la información del caso de forma clara. Puedes adjuntar evidencias como imágenes, documentos, audios o videos para facilitar la revisión del comité.

Protección de identidad Los datos personales no son obligatorios.
1
Información del incidente

Indica el tipo de situación reportada y el área donde ocurrió.

2
Descripción del caso

Describe lo ocurrido con el mayor detalle posible.

3
Evidencias del caso

Adjunta archivos que ayuden a respaldar la denuncia.

Para el prototipo se recomienda usar archivos pequeños. En un sistema real se guardarían en un servidor seguro.
4
Contacto opcional

Este campo no es obligatorio si deseas mantener el anonimato.

La denuncia será registrada de forma confidencial.

Al enviar el formulario, el sistema generará un código de seguimiento y un PIN. Guarda esos datos para consultar el avance del caso.

¿Qué puedes denunciar?
  • Humillaciones o burlas constantes.
  • Gritos, amenazas o intimidación.
  • Aislamiento dentro del trabajo.
  • Abuso de autoridad.
  • Sobrecarga intencional de tareas.
  • Comentarios ofensivos o discriminatorios.
